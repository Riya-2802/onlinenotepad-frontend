# onlinenotepad-frontend
--OnlineNotepad Frontend is the frontend of the OnlineNotepad project, built to provide a user-friendly interface for creating and managing notes.
--Users can create, edit, delete, and share notes with others while managing access through permissions.
--The application also supports team creation, adding members, assigning roles, and controlling permissions based on user roles for secure collaboration.
# technology: react.js and tailwind css
